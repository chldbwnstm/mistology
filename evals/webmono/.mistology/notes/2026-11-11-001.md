## 문제 상황
Next.js Edge 미들웨어에서 JWT 서명 검증 시 Node 내장 crypto 모듈 참조로 런타임 실패

## v1 (오답) 2026-11-11
- 한 것: apps/web/src/middleware.ts에서 Node 전용 node:crypto 헬퍼를 직접 import해 토큰 서명을 검증
- 틀린 증거: EdgeRuntimeError: The edge runtime does not support Node.js 'crypto' module
- 왜 틀렸나: 처음부터 틀림: Next.js Edge 런타임은 V8 격리 환경이라 Node 내장 crypto 대신 Web Crypto API만 지원함

## v2 (현재 정답) 2026-11-11
- 한 것: packages/auth/src/jwt의 verifyEdgeJwt를 Web Crypto crypto.subtle.verify(HMAC-SHA256) 기반으로 구현해 호출
- 확인 근거: pnpm --filter web test:edge 미들웨어 인증 통과
- 다음에는: apps/web/src/middleware.ts 수정 시 결합된 packages/auth/src/jwt가 Edge 호환 API만 쓰는지 함께 확인
