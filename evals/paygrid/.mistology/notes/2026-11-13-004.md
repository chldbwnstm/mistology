Enforce configurable webhook timestamp replay tolerance in `services/gateway/webhook.py` without allowing future-timestamp bypass

## v1 (오답) 2026-11-13
- 한 것: Checked `if now_ts - ts > tolerance_sec: return False` inside `verify_webhook`
- 틀린 증거: SecurityAuditError: Forged future webhook timestamp t=9999999999 accepted because `now_ts - ts` was negative (-8299999999 <= 300)
- 왜 틀렸나: 처음부터 틀림: 단방향 뺄셈(`now_ts - ts > tolerance_sec`)은 미래 시점 타임스탬프가 음수가 되어 검증을 우회함

## v2 (현재 정답) 2026-11-13

- 확인 근거: Security replay unit tests (past expired and future forged timestamps) passed
- 다음에는: `webhook.py`에 `tolerance_sec`을 추가·변경할 때는 단방향 `now_ts - ts > tolerance_sec`을 절대 쓰지 말고 반드시 양방향 `abs(now_ts - ts) <= tolerance_sec` 검사를 사용할 것
