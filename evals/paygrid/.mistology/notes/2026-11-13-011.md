## 문제 상황
Prevent clients from resetting sliding-window rate limits by rotating API key secrets

## v1 (오답) 2026-11-13
- 한 것: Keyed `SlidingWindowRateLimiter._hits` dictionary by `sha256(raw_api_key)`
- 틀린 증거: RateLimitBypassError: Client rotated secret suffix via self-serve API and bypassed 60s window quota
- 왜 틀렸나: 처음부터 틀림: 전체 토큰 해시를 버킷 키로 쓰면 시크릿 회전 때마다 새 버킷이 생성됨

## v2 (현재 정답) 2026-11-13
