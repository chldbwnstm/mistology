## 문제 상황
Support zero-decimal (JPY, KRW, VND) and three-decimal (BHD, KWD) ISO-4217 currencies in minor-unit conversion

## v1 (오답) 2026-11-13
- 한 것: Hardcoded `if currency == "JPY": scale = 1 else: scale = 100` inside `to_minor_units`
- 틀린 증거: AssertionError: 500000 != 5000 when converting 5000 KRW in tests/test_public.py
- 왜 틀렸나: 처음부터 틀림: JPY만 예외 처리해 KRW 같은 다른 소수점 0자리 통화에 100이 곱해짐

## v2 (오답, 한때 정답) 2026-11-13
- 한 것: Added `ZERO_DECIMAL_CURRENCIES = {"JPY", "KRW"}` set and used `scale = 1 if code in ZERO_DECIMAL_CURRENCIES else 100` in services/fx/currency.py
- 확인 근거: python3 -m unittest tests/test_public.py (KRW conversion passed)
- 다음에는: Check ISO-4217 zero-decimal set before adding Asian currencies
- 틀린 증거: ValueError: Precision overflow for BHD (exponent=2): 1.250 when onboarding Bahraini Dinar (3 decimals)
- 왜 틀렸나: 바뀌어서 틀려짐: ZERO_DECIMAL_CURRENCIES 이분법(0 또는 2자리)으로는 BHD·KWD·JOD 같은 3자리 소수점 통화(scale=1000)를 표현할 수 없음

## v3 (현재 정답) 2026-11-13
- 한 것: Replaced boolean set with `CURRENCY_EXPONENTS: dict[str, int]` (`0`, `2`, `3`) using `Decimal(10) ** exp` in `services/fx/currency.py`
- 확인 근거: python3 -m unittest discover -s tests (USD, KRW, BHD minor unit conversion tests passed)
- 다음에는: 새 통화 추가 시 반드시 `services/fx/currency.py`의 `CURRENCY_EXPONENTS`에 정확한 소수점 지수(0, 2, 3)를 등록할 것
