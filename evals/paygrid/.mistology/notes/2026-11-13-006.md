## 문제 상황
Preserve trailing CRLF bytes in `extract_wire_body` so enterprise proxy webhook HMAC signatures do not fail

## v1 (오답) 2026-11-13
- 한 것: Called `body.rstrip(b"\r\n")` unconditionally when parsing raw HTTP frames in `raw_body.py`
- 틀린 증거: WebhookSignatureMismatchError: HMAC digest mismatch on CRLF-terminated JSON payload from Envoy ingress
- 왜 틀렸나: 처음부터 틀림: 발신자가 서명한 원본 바이트 끝에 `\r\n`이 포함되어 있는데 파서가 이를 제거해 HMAC 해시가 달라짐

## v2 (현재 정답) 2026-11-13
- 한 것: Keep `preserve_wire_bytes: bool = True` as default in `services/gateway/raw_body.py` and never strip or re-serialize JSON before `verify_webhook`
- 확인 근거: python3 -m unittest tests/test_public.py (CRLF body signature test passed)
- 다음에는: 웹훅 바이트 처리 시 절대 `.strip()`이나 `json.dumps(json.loads(...))` 정규화를 먼저 수행하지 말 것
