## 문제 상황
Avoid `TypeError: unsupported operand type(s) for |` when running tests under macOS/CI system Python 3.9

## v1 (오답) 2026-11-13
- 한 것: Wrote PEP 604 `str | None` annotations without `from __future__ import annotations`
- 틀린 증거: TypeError: unsupported operand type(s) for |: 'type' and 'NoneType' on /usr/bin/python3 (3.9.6)
- 왜 틀렸나: 처음부터 틀림: 런타임 평가 시점에 Python 3.9는 `type | None` 연산자를 지원하지 않음

## v2 (현재 정답) 2026-11-13
- 한 것: Add `from __future__ import annotations` at the top of every Python module using union or generic type annotations
- 확인 근거: /usr/bin/python3 -m unittest discover -s tests passed on Python 3.9.6
- 다음에는: 새 파이썬 모듈 작성·함수 시그니처에 `| None` 추가 시 파일 최상단 `from __future__ import annotations` 여부를 먼저 확인할 것
