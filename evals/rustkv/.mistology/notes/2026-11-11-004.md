## 문제 상황
세그먼트 최대 크기 설정값에 0이 전달될 때 청크 분할 계산에서 0 나누기 패닉 발생

## v1 (오답) 2026-11-11
- 한 것: 사용자 플래그에서 파싱한 max_segment_bytes 정수를 검증 없이 분할 산식에 그대로 대입
- 틀린 증거: ConfigOverflowError: max_segment_bytes 0 triggers divide-by-zero
- 왜 틀렸나: 처음부터 틀림: 하한 경계 검사가 없어 0 바이트 입력이 런타임 나눗셈까지 도달함

## v2 (현재 정답) 2026-11-11
- 한 것: max_segment_bytes 진입부에서 0 입력을 즉시 거부하고 MIN_SEGMENT_BYTES(4096) 하한을 강제
- 확인 근거: cargo test -p rustkv-cli config_bounds 통과
- 다음에는: 용량 설정 파서 추가 시 0과 최소 블록 하한을 진입부에서 먼저 검증한다
