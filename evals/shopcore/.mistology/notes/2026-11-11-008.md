## 문제 상황
주문 배송지 우편번호 정수 변환 시 앞자리 0 유실

## v1 (오답) 2026-11-11
- 한 것: 우편번호 문자열을 int(code)로 변환해 숫자 여부를 검사한 뒤 str로 다시 저장
- 틀린 증거: PostalCodeFormatError: postal code 1234 must be 5 digits
- 왜 틀렸나: 처음부터 틀림: 01234처럼 0으로 시작하는 5자리 우편번호를 정수로 변환하면 앞자리 0이 사라져 4자리가 됨

## v2 (현재 정답) 2026-11-11
- 한 것: 정수 형변환 없이 문자열 상태에서 길이 5와 ASCII 숫자 여부(isascii, isdigit)만 검증해 원형 유지
- 확인 근거: 01234 우편번호 보존 및 자릿수 오류 거부 테스트 통과
- 다음에는: 우편번호·전화번호 같은 식별 코드는 절대 int로 변환하지 말고 문자열로 검증
