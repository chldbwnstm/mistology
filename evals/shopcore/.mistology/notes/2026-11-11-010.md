## 문제 상황
환경변수 불리언 문자열 false가 True로 잘못 파싱됨

## v1 (오답) 2026-11-11
- 한 것: 파이썬 내장 bool(os.getenv(...))로 환경변수 문자열을 불리언 변환
- 틀린 증거: ConfigBooleanError: invalid boolean value 'disabled'
- 왜 틀렸나: 처음부터 틀림: 파이썬에서 비어 있지 않은 문자열 bool('false')는 항상 True로 평가됨

## v2 (현재 정답) 2026-11-11
- 한 것: parseBoolEnv에서 1/true/yes와 0/false/no만 허용 목록으로 대소문자 구분 없이 파싱하고 나머지는 ConfigBooleanError 발생
- 확인 근거: true/false 문자열 파싱 및 비표준 문자열 예외 테스트 통과
- 다음에는: 환경변수 불리언 파싱은 내장 bool() 대신 반드시 parseBoolEnv를 사용
