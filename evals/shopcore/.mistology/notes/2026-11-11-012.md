## 문제 상황
레거시 주문 내역 XML 내보내기 시 CP949 인코딩 오류 발생

## v1 (오답) 2026-11-11
- 한 것: 유니코드 특수문자가 포함된 상품명을 CP949로 직렬화해 내보냄
- 틀린 증거: XmlEncodingError: invalid CP949 byte
- 왜 틀렸나: 처음부터 틀림: CP949가 표현하지 못하는 이모지·다국어 문자가 주문 데이터에 포함됨

## v2 (현재 정답) 2026-11-11
- 한 것: XML 선언과 출력 스트림을 UTF-8로 통일 (이후 legacy_xml 모듈 전체 삭제됨)
- 확인 근거: UTF-8 XML 내보내기 확인 후 JSON API 전환 완료에 따라 모듈 폐기
- 다음에는: 레거시 XML 모듈은 폐기되었으므로 신규 내보내기는 UTF-8 JSON을 사용
